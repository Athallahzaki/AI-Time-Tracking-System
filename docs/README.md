# Dokumen Acuan

- `ARCHITECTURE.md`: batas tanggung jawab engine, backend, dan frontend.
- `ENGINE_PROTOCOL.md`: kontrak komunikasi TCP NDJSON.
- `WORKPLAN.md`: urutan implementasi dan milestone.
- `PROJECT_STRUCTURE.md`: struktur folder yang dituju.

Implementasi yang sudah diverifikasi dan selisih terhadap workplan dicatat pada
`../WORKPLAN_STATUS.md`. Bila dokumen acuan dan implementasi berbeda, jangan
memindahkan kebijakan bisnis ke engine dan jangan membuat import langsung antara
engine dan backend.
